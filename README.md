**How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?**

I wrote programs that are maintanable, readable, and adaptable by making code that is lighttweight and properly commented. I tried to ensure that my work was not doing too many extra steps (_although I did take a few liberties when it came to changing the color of the selection tool, and allowing users to sort by animals_) However, I focused more on true functionality. The advantages of keeping things simple means that, in the future, should I want to change a method, I should have no trouble adjusting it to fit my new ideas. I could use this same module for really any database I desire. I would have to change a few key things such as the login and the access points but at the end of the day, this program is pretty adaptable. 

**How do you approach a problem as a computer scientist? Consider how you approached the database or dashboard requirements that Grazioso Salvare requested. How did your approach to this project differ from previous assignments in other courses? What techniques or strategies would you use in the future to create databases to meet other client requests?**

I really tried to focus on building things one step at a time and properly testing functionality before moving onto step 2. As an artist, this goes against my inclination to work on the canvas as a whole and build it together so everything flows nicely. However, it's important to ensure that each layer works before adding a new layer. This differs from assignments in the past when I was new to CS where, if something wasn't working, I would get frustrated and start a different piece of the puzzle. That really isn't how CS works and I've learned that having another person experienced in CS look at your work is quite helpful, or simply stepping back for a time to build a renewed mindset. If all else fails, there really isn't any problem that hasn't already been solved by someone else so YouTube really helps to illustrate what other's have done to solve a problem.

Computer Scientists are problem solvers that work in many different fields including business, science, and social work. Computer Scientists are analysts and developers that create software to perform mundane or difficult tasks and drive innovation forward. This matters because a large part of our society today is built on CS. The fact that I'm writing this right now is thanks to someone in CS.
